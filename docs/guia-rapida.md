| Administrador | `svd.sytes.net/admin` | `admin@svd.test` | `admin` |

> Cuentas de prueba. Pide tu cuenta real y cambia estas contraseñas cuando empiecen a usar el sistema.

---

## Hacer una venta (lo más usado)

1. **Ventas → Remisiones → Nueva remisión** (o desde el celular, "Nueva remisión").
2. Elige el **cliente**.
3. Elige **tipo de pago** y **ruta**.
4. **Agrega los productos** y sus cantidades (el total se calcula solo).
5. El cliente **firma** (en pantalla o subiendo una foto).
6. **Crear**. → Se envía el comprobante por correo automáticamente.

## Tareas frecuentes

| Quiero… | Voy a… |
|---------|--------|
| Registrar un cliente | Catálogo → Clientes → Nuevo cliente |
| Ponerle precio especial a un cliente | Editar el cliente → sección "Productos del Cliente" |
| Cambiar el precio de un producto (a todos) | Catálogo → Catálogo de Productos → editar precio |
| Ver/descargar reportes | Ventas → Reportes → poner filtros → descargar Excel |
| Imprimir un comprobante | Abrir la remisión → Imprimir PDF |
| Reenviar un comprobante por correo | Abrir la remisión → Reenviar copia |
| Crear un usuario | Configuración → Usuarios → Nuevo usuario |
| Cambiar logo / datos de empresa | Configuración → Configuración |

---

## 3 cosas clave que debes saber

1. **Cliente nuevo = ya tiene todos los productos** con precio normal. No los agregas uno por uno.
2. **El precio especial de un cliente no cambia** aunque subas el precio general.
3. **Las ventas guardan el precio del momento.** Cambiar precios después no altera ventas viejas.

---

## Si eres vendedor

- Entras a **svd.sytes.net/vendedor** o usas la **app del celular**.
- Ves solo **tus** ventas y tus números (hoy, mes, total).
- Registras ventas, el cliente firma en pantalla, y listo.
- En **Mis Reportes** filtras y descargas tus ventas a Excel.

---

## Problemas comunes

- **No me deja entrar a /admin y soy vendedor** → usa `/vendedor`.
- **Un producto no aparece para un cliente** → está "no disponible" para ese cliente o inactivo en el catálogo.
- **Olvidé mi contraseña** → pídele al administrador que la restablezca.
